# Study Plans

This folder contains comprehensive study plans for technical interview preparation.

## Available Plans

### 1. System Design 45-Day Master Plan

A complete 45-day study plan covering:
- **SOLID Principles** (Days 1-5)
- **Object-Oriented Design** (Days 6-18)
- **System Design Fundamentals** (Days 19-32)
- **System Design Interview Problems** (Days 33-45)

**Files:**
- `system-design-45-day.md` - Full markdown documentation
- `system-design-45-day.html` - Standalone interactive HTML version (can be opened in any browser)

**Web Version:**
Access the interactive study plan at `/study-plans` on the website with:
- ✅ Progress tracking with checkboxes
- ✅ Real-time progress statistics
- ✅ Collapsible sections
- ✅ Export/import progress
- ✅ Local storage persistence

## Usage

### Standalone HTML Version
Open `system-design-45-day.html` in any browser - no server required. Your progress is saved in browser localStorage.

### Integrated Web Version
Navigate to the Study Plans page on the website for the same interactive experience integrated with the site theme.

### Markdown Version
Use `system-design-45-day.md` for reading offline or printing.

## Study Plan Structure

Each day includes:
- **Topics**: What concepts to learn
- **Practice**: Hands-on exercises
- **Notes**: What to document for future reference

## Time Commitment
- 1.5 hours per day
- 45 days total
- Covers both Low-Level Design (LLD) and High-Level Design (HLD)
